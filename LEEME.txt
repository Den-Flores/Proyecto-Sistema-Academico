================== SISTEMA ACADÉMICO ================== 

Descripción del proyecto

El presente proyecto consiste en el desarrollo de una aplicación móvil denominada "Sistema Académico", elaborada en React Native con Expo. 
La aplicación cuenta con un menú principal desde donde el usuario puede ingresar al módulo de Estudiantes o Docentes.

***** Funciones implementadas: *****
    Módulo Estudiante
    - Menú principal del estudiante.
    - Visualización de datos personales editables.
    - Consulta del historial académico.
    - Consulta del récord académico.
    - Visualización del horario de clases.

    Módulo Docente
    - Selección de la materia mediante una lista desplegable.
    - Registro de estudiantes y notas.

***** Conceptos de React Native aplicados *****
Durante el desarrollo del proyecto se utilizaron los siguientes componentes y conceptos:
- View para organizar la estructura de cada pantalla.
- Text para mostrar información al usuario.
- Image para representar íconos e imágenes de la aplicación.
- TextInput para la captura y modificación de datos.
- TouchableOpacity y Pressable para crear botones personalizados e interactivos.
- ScrollView para permitir el desplazamiento vertical cuando el contenido supera el tamaño de la pantalla.
- StatusBar para controlar la barra superior del dispositivo.
- useState para el manejo de estados y actualización dinámica de la interfaz.
- StyleSheet para separar completamente la lógica de los estilos, promoviendo la modularización del proyecto.

***** Estructuras de datos utilizadas *****
Para simular el funcionamiento del sistema sin utilizar bases de datos se emplearon:
- Arreglos unidimensionales.
- Arreglos bidimensionales.
- Arreglos de objetos para representar materias, notas, paralelos y horarios.
- Generación aleatoria (Random) para asignar notas, paralelos y algunos datos de ejemplo.

Además, se implementó la lógica académica para simular el avance del estudiante entre gestiones, considerando materias aprobadas, reprobadas y abandonadas.
 
***** Navegación *****
La navegación entre las diferentes pantallas fue desarrollada mediante Expo Router utilizando el componente Link, permitiendo desplazarse entre:
- Pantalla principal.
- Menú de estudiantes.
- Menú de docentes.
- Datos personales.
- Historial académico.
- Récord académico.
- Horario.
También se implementó un menú de navegación inferior con botones de Inicio y Volver para facilitar el acceso entre las diferentes ventanas de la aplicación.

***** Observaciones *****
Este proyecto tiene fines académicos. La información utilizada es simulada y se maneja únicamente mediante estructuras de datos en memoria, sin conexión a bases de datos.
